# Изучаемый язык и выбор голоса: что доделать на клиенте

План работ по серверным изменениям. Контракт — в
[`CLIENT_SPEC.md §6.0`](./CLIENT_SPEC.md) (язык, акценты, каталог) и
[`TTS_CLIENT_SPEC.md`](./TTS_CLIENT_SPEC.md) (голоса, прослушивание); здесь —
что именно тронуть в приложении и в каком порядке.

## 1. Что изменилось в контракте

| Было | Стало |
| --- | --- |
| `studied_language` — свободная строка в профиле | код из `GET /v1/languages`; неизвестный — `422`, очистить нельзя |
| каталог общий для всех | каталог **одноязычный**: `/v1/lessons`, `/v1/folders`, `/v1/library` без параметра отдают язык из профиля |
| `accent` — `US`/`UK`, зашиты в клиенте | акценты приходят внутри языка; у английского их три (`US`, `UK`, **`AU`**), у остальных нет |
| у урока нет языка | `lesson.language`, `folder.language`; `lesson.accent` может быть **`null`** |
| голос и язык озвучки — настройка сервера | `GET /v1/tts/voices`, `voice`/`accent` в запросе, `POST /v1/tts/preview` |

Новых обязательных полей в запросах нет: язык сервер подставляет из профиля сам.
Ломается только разбор ответов — см. §4.

## 2. Порядок работ

Каждый этап оставляет приложение в рабочем состоянии.

1. **Разбор ответов.** `accent` → nullable, значение `AU` перестаёт быть
   неизвестным, в `LessonDto`/`FolderDto` появляется `language`. Это правка на
   полчаса, но без неё после деплоя сервера приложение падает на первом же
   уроке — делать её первой и выкатывать отдельно (§4.1).
2. **Справочник и выбор языка.** `GET /v1/languages`, экран «Settings»:
   выпадающий список языков, `PATCH /v1/me { studied_language }`, сброс кеша и
   каталога после успешного ответа (§3.4).
3. **Каталог.** Ничего не передавать в запросах — сервер сам отдаёт нужный язык;
   фильтр по акценту показывать, только если у выбранного языка непустой
   `accents`; курсоры и «водяной знак» синхронизации завести на язык.
4. **Создание урока.** Выбор акцента строить из справочника языка, у языков без
   акцентов поле не показывать и не слать. `language` в теле не передавать.
5. **Озвучка (owner).** Список голосов, кнопка ▶ у каждого, выбранный голос в
   `POST /v1/tts/synthesize`; выбор акцента озвучки — там же, где и голос, и
   только у языков с акцентами.

## 3. По слоям

### 3.1 `data/models`

```dart
class LanguageDto { String code; String name; String nativeName;
                    bool isDefault; List<AccentDto> accents; }
class AccentDto   { String code; String name; bool isDefault; }
class VoiceDto    { String name; String description; }
```

- `LessonDto`: `+ String language`, `String? accent` (было non-null);
- `FolderDto`: `+ String language`;
- ответ синтеза и превью: `+ voice`, `+ language`, `+ accent` (nullable),
  у превью ещё `text` — проговорённая фраза;
- `LessonModel` (sqflite) — тоже колонка `language`, см. §3.3.

### 3.2 `data/datasources`

- новый `LanguageRemoteDataSource.getLanguages()` — ответ можно держать в памяти
  на сессию, справочник меняется релизом сервера;
- `TtsRemoteDataSource`: `getVoices()`, `preview({voice, accent})`,
  а `synthesize` получает необязательные `voice` и `accent`;
- `LessonRemoteDataSource` и папки **не трогаем**: параметр `language` серверу
  передавать не нужно, он берёт его из профиля. Передавать явно — только если
  появится экран «посмотреть каталог другого языка».

### 3.3 Локальный кеш

- в таблицы `lessons` и `folders` добавить `language`;
- у старых записей языка нет, и достроить его на клиенте неоткуда — **проще
  поднять версию схемы и снести кеш**: это зеркало сервера, а не данные
  пользователя, полная перезагрузка стоит одного запроса;
- «водяной знак» (`updated_at` последней дельты) хранить **на язык**:
  `last_sync_at_<code>`. Один общий знак после переключения языка приведёт к
  тому, что новый каталог приедет наполовину.

### 3.4 Смена языка — отдельный сценарий

Порядок важен, иначе поверх нового каталога ляжет старый:

1. `PATCH /v1/me { studied_language }` и **дождаться `200`** (при `422` показать
   сообщение и оставить прежний язык);
2. очистить кеш уроков и папок, «водяной знак», курсоры пагинации;
3. сбросить фильтры каталога — акцент прошлого языка сервер не примет (§4.4);
4. перезагрузить `/v1/library` с нуля (без `since`) и перерисовать экран.

Стоит предупредить в UI: «список уроков сменится» — исчезновение всего каталога
после переключения выглядит как потеря данных, если этого не ждёшь.

### 3.5 Экран озвучки (owner)

- список голосов из `GET /v1/tts/voices` (имя + характеристика), выбор по
  умолчанию — `default_voice`; `voices: []` — провайдер выбора не даёт, весь блок
  прятать;
- у каждого голоса кнопка ▶ → `POST /v1/tts/preview { voice }`: сервер сам
  подставит фразу на текущем языке. Первое нажатие тратит одну озвучку из
  суточной корзины, повторные — нет (кеш), поэтому кнопку не блокировать;
- рядом — остаток `GET /v1/tts/quota` (`day.remaining`): корзина маленькая;
- выбор акцента озвучки — из `accents` текущего языка, у языков без акцентов
  не показывать;
- сэмпл превью **не класть** в кеш аудио уроков — это служебная фраза.

## 4. Ловушки

**4.1 Разбор `accent` — самое вероятное место поломки.** Если в клиенте
`enum Accent { us, uk }`, то после деплоя сервера он встретит `AU` (новый акцент
английского) и `null` (у французского и турецкого) и упадёт на разборе списка
уроков. Хранить акцент строкой, а подписи брать из справочника языка.

**4.2 Кеш от старой версии.** Записи без `language` в выборку по языку не
попадут и повиснут мёртвым грузом — сносить кеш при обновлении схемы (§3.3).

**4.3 Дельта по `since` теперь языковая.** В кеш приезжает только текущий язык.
Смена языка дельтой не выражается — только полная перезагрузка.

**4.4 Фильтр акцента, переживший смену языка,** даст `422` на первом же запросе
каталога: сервер сверяет акцент с языком выборки. Сбрасывать вместе с языком.

**4.5 Папка одноязычна.** Урок другого языка в неё не положить (`422`). На
практике не всплывёт — в выборе уроков и так только текущий язык, — но ошибку
показать по-человечески, а не «неизвестная ошибка сервера».

**4.6 `recent_lesson_ids` из `/v1/progress`** могут указывать на уроки другого
языка (история сохраняется при переключении). По прямой ссылке такой урок
открывается нормально; решите, показывать его в «недавних» или отфильтровать по
`lesson.language`.

**4.7 `language` в теле `PUT`** слать не нужно. Если всё же шлёте — значение
обязано совпадать с языком профиля (у существующего урока — с его собственным),
иначе `422`. Язык созданного урока правкой не меняется.

**4.8 Один и тот же текст разными голосами** возвращает разное аудио, но **один
и тот же** текст тем же голосом придёт из кеша (`cached: true`) с тем же
`audio_id` — это не сбой, а экономия лимита.

## 4а. Допущения реализации

`CLIENT_SPEC.md` и `TTS_CLIENT_SPEC.md` описывают прежний контракт, поэтому
формы ответов взяты из §3 этого плана. Что заложено в клиент — сверить с
сервером:

| Запрос | Ответ, который клиент разбирает |
| --- | --- |
| `GET /v1/languages` | `{"languages": [{code, name, native_name, is_default, accents: [{code, name, is_default}]}]}`; ключ `items` тоже принимается |
| `GET /v1/tts/voices` | `{"voices": [{name, description}], "default_voice": "…"}`; ключ `items` тоже принимается |
| `POST /v1/tts/preview` | `{voice}` (+ `accent` у языков с акцентами) → объект аудио плюс `text` и `cached` |
| `POST /v1/tts/synthesize` | `{text}` плюс необязательные `voice` и `accent` |

Прочие допущения:

- `lesson.accent` и `folder.language` — строки; пустая строка читается как
  «не задан»;
- у превью `audio_id` скачивается тем же `GET /v1/audio/{id}/file`, что и
  аудио уроков, но кладётся во временную папку `tts_samples`;
- фильтр каталога остаётся клиентским: `accent` в `GET /v1/lessons` не
  уходит, поэтому ловушка §4.4 не срабатывает.

## 5. Чек-лист приёмки

Полный — в `CLIENT_SPEC.md` («Чек-лист приёмки») и `TTS_CLIENT_SPEC.md §10`.
Коротко, что проверить руками:

- [ ] список языков в «Settings» пришёл с сервера, выбран текущий;
- [ ] переключение на французский: каталог и лента показывают только
      французское, фильтр акцента исчез, кеш перечитан;
- [ ] переключение обратно на английский возвращает прежний каталог;
- [ ] у английского в фильтрах и на экране создания три акцента, включая `AU`;
- [ ] урок на французском создаётся без поля акцента, в ответе `accent: null`;
- [ ] список голосов и ▶ у каждого работают, повторное прослушивание мгновенно и
      не тратит квоту;
- [ ] озвучка урока на французском звучит по-французски без единого поля языка
      в запросе;
- [ ] один текст, озвученный двумя голосами, звучит по-разному.
