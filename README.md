# Shado

Приложение для изучения английского по технике **shadowing**: загружаете аудио
и текст, вручную размечаете границы кусков на волне, затем проигрываете и
зацикливаете каждый кусок, повторяя за диктором.

Работает полностью локально: ни сети, ни бэкенда, ни распознавания речи —
вся разметка ручная.

## Запуск

```bash
flutter pub get
dart run build_runner build   # freezed + json_serializable
flutter run
```

Целевые платформы — Android, iOS и Windows/Linux.

### Чем отличается десктоп

`just_audio`, `just_waveform` и `sqflite` нативных реализаций под Windows и
Linux не имеют, поэтому там подставляются замены (см.
`lib/core/platform/platform_setup.dart`, вызывается из `main` до `runApp`):

| Задача | Android / iOS | Windows / Linux |
| --- | --- | --- |
| Воспроизведение | `just_audio` | `just_audio_media_kit` (libmpv) |
| Пики волны | `just_waveform` | `flutter_soloud` (miniaudio) |
| База | `sqflite` | `sqflite_common_ffi` |

Отсюда два отличия в поведении на десктопе:

- форматы аудио — `mp3, wav, flac, ogg` вместо `mp3, m4a, wav`: декодер
  miniaudio не читает m4a/aac;
- волна рисуется по RMS-огибающей и симметрична относительно центра, тогда как
  `just_waveform` даёт настоящие min/max. Огибающая нормализуется по самому
  громкому месту, чтобы границы фраз были видны. Кеш лежит рядом с аудио в
  `<файл>.peaks` (на мобильных — `<файл>.wave`); для предпросмотра на экране
  создания кеш не пишется — файл ещё чужой (`loadPeaks(cache: false)`).

## Как пользоваться

1. Вкладка **«Добавить»**: название, текст с кусками через `|`, кнопка выбора
   аудио. Список форматов зависит от платформы — см. выше.
2. Как только файл выбран, под формой появляется его волна с метками границ:
   куски раскладываются равномерно, метки двигаются сразу, ещё до создания
   урока. Правка текста подгоняет разметку под новое число кусков — уже
   расставленные метки с начала сохраняются.
3. «Создать урок»: аудио копируется в каталог приложения вместе с размеченными
   границами.
4. Экран урока: переключатель «Медленно / Нормально» (0.75× / 1.0×), список
   кусков с кнопками Play и Loop, внизу — волна с перетаскиваемыми метками
   границ. Для `N` кусков метка одна на каждый внутренний стык — `N - 1` штука.
5. Кнопка ✏️ в шапке урока открывает правку: там же меняются название,
   разбивка текста на куски и границы на волне. После сохранения урок
   перечитывается, плеер сбрасывается.

### Волна

Волна общая для всех трёх экранов (`WaveformCard` → `WaveformEditor`) и
растягивается, чтобы метку можно было поставить точнее:

| Действие | Мышь / трекпад | Сенсор |
| --- | --- | --- |
| Масштаб | `Ctrl` + колесо, щипок на трекпаде, кнопки «+/−» | щипок, кнопки «+/−» |
| Сдвиг | колесо, перетаскивание мимо меток | перетаскивание мимо меток |
| Сброс масштаба | клик по «1.0×» | тап по «1.0×» |

Метка, доведённая до края окна, тянет волну за собой. Сверху идёт шкала
времени с круглым шагом, у перетаскиваемой метки показывается точное время, в
кусках — их номера.

## Архитектура

Чистая архитектура, feature-first; зависимости направлены внутрь:
`presentation → domain ← data`.

```text
lib/
  core/            константы, тема, роутер, типы ошибок, форматирование
  features/lessons/
    domain/        entities, repositories (интерфейс), usecases
    data/          models (freezed + json), datasources, repositories
    presentation/  pages, widgets, controllers (riverpod)
```

Домен не знает ни о Flutter, ни о БД, ни об аудиопакетах. Локальное хранилище
(sqflite) спрятано за `LessonLocalDataSource`, аудиофайлы — за
`AudioFileDataSource`, пики волны — за `WaveformDataSource`.

### Швы под будущий бэкенд

- Идентификаторы — строковые UUID, совпадут с серверными.
- `LessonModel` / `SegmentModel` уже JSON-сериализуемы: готовые DTO.
- `LessonRepositoryImpl` — единственное место, куда добавится
  `LessonRemoteDataSource` и синхронизация; домен и UI не изменятся.
- `Lesson.audioPath` не завязан на «только локальный файл»: позже там может
  оказаться URL.

## Тесты

```bash
flutter test
```

Покрыта доменная логика: равномерная разбивка, пересчёт границ, разбор текста
по разделителю, нормализация границ и подгонка разметки под изменившееся число
кусков. Виджет-тесты на `WaveformEditor` проверяют перетаскивание меток,
неподвижность крайних границ и что на растянутой волне тот же жест сдвигает
метку на меньшее время.

Инфраструктуру десктопа (длительность через libmpv, пики через miniaudio,
воспроизведение куска, запись урока в sqlite) проверяет интеграционный тест на
сгенерированном wav — он требует запущенной платформы:

```bash
flutter test integration_test/desktop_pipeline_test.dart -d windows
```
